# ULTIMATE CAR WORLD 🏙️🚗

**عالم السيارات المطلق** — لعبة قيادة وعالم مفتوح ثلاثي الأبعاد مع اقتصاد حقيقي YER، لعب جماعي، محادثة صوتية، ولوحة إدارة.

## 🎮 طريقة التشغيل السريع (بدون أي خادم)
افتح الملف **`UCW-اللعبة.html`** في المتصفح مباشرة — لا يحتاج Node ولا خادم، يحفظ تقدمك تلقائياً.

## 🖥️ التشغيل الكامل (Backend + Client + Multiplayer)
```bash
cd backend
npm install
npm run seed
npm start
```
- اللعبة: http://localhost:8080/play
- لوحة الإدارة: http://localhost:8080/admin
- فحص الخادم: http://localhost:8080/health

### أنشئ حساب مالك (بعد التشغيل الأول):
```bash
sqlite3 backend/data/game.sqlite "UPDATE users SET role='owner' WHERE username='yourname';"
```

## 📱 ملف APK للأندرويد
`UCW-v1.2.0.apk` — تطبيق WebView كامل الشاشة، يعمل بوضع أوفلاين.

## 📂 هيكل المشروع
```
UltimateCarWorld/
├── UCW-اللعبة.html     # نسخة ملف واحد تعمل دون خادم
├── UCW-v1.2.0.apk     # تطبيق أندرويد قابل للتثبيت
├── backend/           # خادم Node.js + SQLite + Socket.IO
│   └── src/
│       ├── server.js       # REST API + Multiplayer + Chat + Voice signaling
│       ├── db.js           # قاعدة البيانات
│       ├── security.js     # JWT + صلاحيات الأدوار
│       ├── seed.js         # البيانات الأولية (8 سيارات + 5 مهام)
│       ├── test.js         # اختبارات تكامل (19 اختباراً)
│       └── smoke-test.js
├── client/            # عميل الويب ثلاثي الأبعاد (Three.js)
│   ├── index.html     # واجهة عربية RTL كاملة
│   └── src/
│       ├── main.js        # محرك اللعبة (مدينة، سيارات، فيزياء، مرور، مهام، لعب جماعي)
│       └── offline-api.js # وضع أوفلاين للـAPK
├── admin/             # لوحة الإدارة (HTML مستقلة)
├── apk/               # مصدر تطبيق Android + سكربت البناء
├── unity/             # سكربتات C# للربط مع Unity
├── build-apk.sh       # سكربت بناء APK
└── start.sh           # تشغيل سريع
```

## 📝 ملاحظات
- اللعبة تستخدم Three.js r128/0.160 للرسم ثلاثي الأبعاد.
- العملة هي **الريال اليمني YER** (أعداد صحيحة).
- لا يوجد تكامل دفع حقيقي (قرار أمني).
- المكافآت للمهام تتطلب تحققاً خادمياً (مضاد للغش).
